# DET v8.0 — Deep Existence Theory

DET is a research framework for records, causal order and possible physical
laws. This repository contains software models, conditional
mathematics, finite simulations and experimental-analysis tools. Their evidence
and success criteria are distinct: a passing software check or a conventional
data replay does not establish the physical theory.

**Published research snapshot: 21 October 2026.** The current native result is a
[consolidated conditional theorem package](docs/track_b/native_theorem_package_v1/THEOREM_PACKAGE.md),
with the initial [law-dependence result](docs/track_b/native_theorem_package_v1/LAW_DEPENDENCE.md)
and a [fixed/moving seed family theorem](docs/track_b/native_theorem_package_v1/LAW_FAMILY_SUPPLEMENT.md)
completed by the [singular-law kernel and width proof](docs/track_b/native_theorem_package_v1/SINGULAR_LAW_WIDTH.md).
Start there for the mathematical statements and their dependencies. Later local
work is not part of this published snapshot merely because it appears in a
coordination discussion.

**Fixed raw-budget limit.** The [fixed-budget testing theorem](docs/track_b/native_theorem_package_v1/P4_FIXED_BUDGET_TESTING_LIMIT.md) shows, conditional on an actually admitted small-scale pair and the stated iid observation model, that no fixed finite raw budget uniformly gives low false-positive probability and high power. The identity channel is included. With ABSTAIN, conditional error tolerances whose sum is below one force vanishing decision coverage in the limit. Exact population distinctions at positive scale can remain; this is no physical validation or falsification.

No implementation, sampling or benchmark has run or is authorized. This supplies no native-law, practical-value or physical-validation result.

[The factorial-power family](docs/track_b/native_theorem_package_v1/FACTORIAL_POWER_LAW_FAMILY.md) gives an admitted optional from-empty law for each fixed integer \(q\ge1\), with the height upper bound \(\limsup H_N/N^{1/(q+1)}\le\mathrm e(q+1)\) almost surely. The [quadratic subset-penalty law screen](docs/track_b/native_theorem_package_v1/QUADRATIC_SUBSET_PENALTY_LAW_SCREEN.md) adds an explicit strictly positive optional law in the declared model. The [Ferrers height and retention obstruction](docs/track_b/native_theorem_package_v1/FERRERS_HEIGHT_RETENTION_OBSTRUCTION.md) proves the sharp bound \(|Q|\le H(Q)(H(Q)+1)/2\) for filled coordinatewise Ferrers cell orders. The accepted height bounds then imply that the deletion fraction tends to one almost surely for this unrestricted cell class under the quadratic law and each separately fixed integer factorial-power law \(q\ge2\). At \(q=1\), height alone is inconclusive for unrestricted retention; the previous fixed dense-target result stands. The target is unchanged, and no all-dimension-two or physical claim follows.

The [joint Ferrers obstruction](docs/track_b/native_theorem_package_v1/FERRERS_JOINT_HEIGHT_DENSITY_OBSTRUCTION.md) combines a square-root height upper bound with vanishing incomparable-pair density to show that the deletion fraction to unrestricted filled coordinatewise Ferrers cell orders tends to one almost surely for each separately fixed integer factorial-power law \(q\ge1\), under its own measure. The \(q=1\) conclusion uses the additional density premise; height alone remains inconclusive. No convergence rate follows from the unspecified little-o premise, and no target redesign, all-dimension-two, all-law or physical conclusion is asserted.

The [Bernoulli-subset counterexample](docs/track_b/native_theorem_package_v1/BERNOULLI_SUBSET_LAW_FERRERS_COUNTEREXAMPLE.md) supplies an explicit counterexample to universal negligible unrestricted retention. For each fixed \(p\in(0,1)\), this conditional admitted law has almost-sure lower limits at least \(p\) for height and unrestricted filled Ferrers cell retention fractions, an upper deletion limit at most \(1-p\), and vanishing incomparable-pair density under the same measure. The exact speed \(p\) belongs to the greedy chain, not an exact longest-chain or retention limit. Each fixed dense occupancy/aspect target remains obstructed almost surely; a chain is not two-dimensional geometry. This is optional-law dependence within the declared model, with no physical, all-DET or novelty claim.

law that generates possibilities and the kernel that assigns outcomes. The

## Running and checking

Run commands from the repository root. Consult the selected component's
documentation for dependencies and its execution contract. The standalone
research-check registry supports Python 3.11 or later and uses the standard
library; this does not imply that every research adapter has the same
requirements.

For ordinary repository integration, use the scoped checks in the
[branch workflow](docs/BRANCH_WORKFLOW.md). Research execution is a separate
choice and must respect the current pauses, protected inputs and run approvals.
The [observed replay report](docs/track_b/native_theorem_package_v1/OBSERVED_REPLAY.md)
records a separate, admitted scientific run and its bounded arithmetic review.
The branch workflow records maintenance checks; neither supplies a current
whole-repository pass count or authorizes further scientific execution.

The explicit research registry can list and validate its fixed manifest without
executing a witness suite:

```sh
.venv/bin/python -B scripts/run_research_checks.py --list
.venv/bin/python -B scripts/run_research_checks.py --check
```

Create/select an appropriate Python environment before using those paths. See
[Research checks](docs/RESEARCH_CHECKS.md) for selected-suite execution, source
identity checks and the meaning of a successful finite witness. Its registry
does not discover or execute every research directory.

The historical broad runner is still available:

```sh
python3 run_tests.py
```

It runs research and numerical work, including RET-related studies. It is **not
a routine merge gate** and should not be run while that research is paused.
Individual study entry points and their prerequisites are documented below;
listing them here does not authorize another experiment or consume a holdout.
