## Memo 1: S2/S2b — Bounded-Adversary Retroactive Compressibility

### Hypothesis

A bounded-memory deterministic emulator requires more resources (states, computation) to retrodict a record sequence generated by open becoming than one generated by a deterministic process of comparable complexity.

### Adversary Class

**D0-bounded:** Hidden deterministic emulator with finite memory \(M\), no access to future outcomes, no superdeterministic setting dependence.

### Required Data

- A committed record sequence \(R_{1:T}\) from a system where DET claims openness is active.
- A bounded-memory emulator that attempts to compress/predict the sequence.

### Expected Effect Size

Unknown. If the sequence is computationally complex (high Kolmogorov complexity), even a deterministic generator would resist compression. The signal is the *excess* complexity beyond what a bounded-memory deterministic process would produce.

### Known Constraints

1. A deterministic chaotic system with finite memory can generate sequences indistinguishable from random.
2. A pseudorandom sequence from a short seed is deterministic but incompressible without the seed.
3. S2 cannot defeat D0-bounded unless the memory bound is biologically/physically motivated (e.g., bounded by the system's own state space).

### Feasibility: **LOW for ontology; MEDIUM for model-class discrimination**

S2 can discriminate between model classes (e.g., "this sequence is better fit by a 10-state HMM than a 100-state HMM") but cannot establish ontological openness. It is a model-selection tool, not a metaphysics detector.

### Kill Criterion

If all open-becoming sequences are compressible to within \(\epsilon\) of a bounded-memory deterministic emulator, S2 yields no signal.

### Recommendation

Proceed as a model-complexity analysis tool. Do not frame as an ontology discriminator. P0.5 should implement S2b (bounded-state HMM vs DET kernel comparison) on MAM-0/MAM-Q output sequences.

## Memo 2: S3 — Agent-Involving Unpredictability

### Hypothesis

Systems containing selfhood-bearing regimes (agents) exhibit statistical properties in their record sequences that differ from non-agentic systems with equivalent record-side structure.

### Adversary Class

D0 (HDE), D1 (primitive stochastic).

### Required Data

- Record sequences from agent-involving systems.
- Record sequences from matched non-agentic controls.
- Operational definition of "agent-involving" that does not presuppose agency.

### Expected Effect Size

Unknown. No operational definition exists.

### Known Constraints

1. **Circularity:** We cannot operationally define "agent-involving" without presupposing the agency we aim to detect.
2. **Agency is M:** Agency is already classified as metaphysical. Using it as an independent variable is circular.
3. **Record-side proxies:** Intentions, habits, preferences are record-side and can be modeled. But these predict behavior without requiring an agency primitive.

### Feasibility: **LOW — blocked by circularity**

Until an operational definition of "agent-involving" exists that does not presuppose agency, S3 is not executable. This may be fundamentally impossible if agency is inherently undetectable.

### Kill Criterion

If no operational definition of "agent-involving" can be formulated that does not presuppose agency, S3 is permanently infeasible.

### Recommendation

**Defer indefinitely.** S3 is blocked by the agency quarantine. Revisit only if agency is promoted from M to H through an independent channel.

## Memo 3: S5 — Commit Entropy Cost

### Hypothesis

The commit event (\(\operatorname{Commit}\)) has an irreducible entropy cost that is not present in unitary quantum evolution. This cost produces detectable thermodynamic signatures.

### Adversary Class

D0 (HDE — unitary evolution has no collapse), D1 (primitive stochastic — stochastic transitions may also have entropy cost), D2 (MWE — no collapse, no entropy cost).

### Required Data

- High-precision calorimetry on quantum measurement events.
- Comparison of entropy production in "measurement" vs "unitary pre-measurement" phases.

### Expected Effect Size

If commit is a physical non-unitary event, the entropy cost per bit of pointer record should be at least \(k_B \ln 2\) (Landauer's principle). This is \(~9 \times 10^{-24}\) J/bit at room temperature — far below current experimental resolution for single quantum events.

### Known Constraints

1. **Scale:** Single-bit entropy cost is extremely small.
2. **Background:** Measurement apparatuses produce vastly more entropy than the theoretical minimum.
3. **D1 compatibility:** A primitive stochastic theory could also have an entropy cost for outcome selection; this doesn't discriminate DET from D1.
4. **DET's Commit is bookkeeping in P0.4:** If Commit is merely record-update (P/A), there is no physical entropy cost to compute.

### Feasibility: **LOW experimentally; CONCEPTUALLY BLOCKED by Commit status**

If Commit is bookkeeping, there is no physical entropy cost. If Commit is physical, DET must first specify the physical mechanism.

### Kill Criterion

If Commit is classified as bookkeeping only (P/A), S5 has no physical content. If Commit is promoted to physical, the entropy cost must be specified and shown to differ from D1.

### Recommendation

**Defer.** S5 requires Commit to be physically specified first. Currently Commit is P/A as record-update.

## Memo 4: Collapse-Like Side Effects

### Hypothesis

If measurement involves genuine becoming (not just unitary decoherence), there may be excess noise, energy non-conservation, or coherence loss beyond what standard quantum mechanics predicts.

### Adversary Class

D0, D1, D2 (all predict no excess collapse effects beyond standard decoherence).

### Required Data

- Ultra-precise tests of energy conservation in quantum measurement.
- Tests of coherence loss beyond standard decoherence models.
- Spontaneous radiation/search for collapse signatures (e.g., continuous spontaneous localization tests).

### Expected Effect Size

Very small if any. Objective collapse models (CSL, DP) predict effects at the \(10^{-10}\) to \(10^{-16}\) level relative to standard QM, and these are already constrained by experiment.

### Known Constraints

1. **Existing constraints:** Spontaneous radiation searches, matter-wave interferometry, and optomechanical experiments already place strong bounds on collapse effects.
2. **DET has no collapse model:** DET has not specified a physical collapse mechanism. Without one, there is no quantitative prediction.
3. **D1 compatibility:** A stochastic theory with genuine randomness would produce the same statistics without excess noise.

### Feasibility: **LOW — no DET collapse model exists**

### Kill Criterion

If no DET-specific collapse model is formulated with quantitative predictions, this is not testable.

### Recommendation

**Defer until DET specifies a physical commit/collapse mechanism.** The Peres-Mermin and CHSH correspondence models (D5, D8) are higher priority for establishing quantum compatibility.

### Honest Assessment

No candidate discriminator is currently feasible for establishing ontological openness. The most productive near-term work is:

1. **S2b** as a model-complexity tool (not ontology tool) — implement on MAM-0/MAM-Q output.
2. **D5/D8** — establish quantum compatibility (Peres-Mermin, CHSH) before attempting DET-native derivations.
3. **D3** — operationalize \(q\) as the most promising physical variable; its empirical validation would indirectly support the DET framework even without proving openness.

F8-OPEN remains **closed-current by downgrade** and should not be a P0.5 priority. The P0.5 decision gate (§16.4 of P0.4r1.1) should be evaluated based on physical residue, not on F8-OPEN satisfaction.
