## 3. Exact arithmetic and bounded state

Q256 means a fixed denominator `Q=2^256`, independently of the significant-bit precision of the historical coefficient intervals. Signed integers use lowercase canonical hexadecimal strings (`0` is allowed, `-0` and leading zeros are refused). A rational is a two-string `[numerator,denominator]` pair, reduced with positive denominator. The existing **262144-bit ceiling** applies to checked integer/rational arithmetic. It is not an adaptive precision choice.

Each interval product evaluates all four exact endpoint products, then floors/ceils after division by Q. Complex multiplication has the fixed primitive order `ac`, `bd`, `ad`, `bc`, followed by real `ac-bd` and imaginary `ad+bc`; interval dependencies are not cancelled. Twiddles use exact roots at lengths 2 and 4, then positive half-angle square-root intervals. Integer square-root isolation and explicit squaring inequalities certify every endpoint. First-quadrant bounds are intersected analytically with `[0,1]`. Powers are accumulated in increasing index order, retaining all outward rounding. The stage record binds each base and the complete canonical power-list identity.

The primary uses bit reversal and increasing iterative DIT stages. The validator uses recursive even/odd DIT with the same butterfly graph and primitive order. Final division by `sqrt(M)=128` is followed by outward Q256 rounding; sizes 4 and 16 use exact divisors 2 and 4 only in the declared fabricated transform domain. No libm trigonometry, NumPy FFT or binary64 discrepancy is used as an error certificate.

A row's exact midpoint input is quantized outward once, without silently discarding a half-bit. The retained row proof contains the initial Q256 pairs and all 8193 one-sided midpoint rectangles, with canonical identities of both arrays. The validator independently reconstructs the initial pairs from source fractions before replaying the transform. Compact output rectangles plus deterministic independent replay replace a huge per-butterfly trace; rectangles or stage hashes alone are not accepted as proof of a transform.

Only one original row JSON tree and exact midpoint/radius row are live at a time. The original input has a 64-MiB byte ceiling and each decoded row an 8-MiB ceiling; the actual accepted file is smaller. The primary retains the eight required midpoint-mode rows and their encoded proof records, not every original coefficient tree. The validator independently streams source rows and releases transform temporaries after each replay. Qualification writes and releases each analytic transform artifact before constructing the next; it writes/releases the complete producer object before the full canonical decoder/validator round trip. Reversible mutations restore original slots, with a final complete canonical fixture-identity check. No large fixture deep copies or memoized proof-success shortcuts are used.

For a rectangle `[a,b]+i[c,d]` on the Q grid, use integer center numerators `x=a+b`, `y=c+d` and radius numerators `t=b-a`, `s=d-c`, with denominator `D=2Q`. The response sums accumulate integer products before creating reduced fractions. For each band, the transform-only error is accumulated as

`w (|x_i| t_j + t_i |x_j| + t_i t_j + |y_i| s_j + s_i |y_j| + s_i s_j) / D^2`.

Both implementations independently construct these sufficient sums.

## 4. Scientific checks and complete result schema

True `A` annihilates constants by the held theorem. Only that true DC response is omitted from covariance sums. A midpoint row may have nonzero DC. The midpoint Parseval comparison therefore includes its full real DC center/radius and uses **transform error only**, excluding coefficient `alpha`. For real rows the imaginary DC and Nyquist components are analytically zero; both modules first require their recorded rectangles to contain zero, then replace only those imaginary components by zero in response sums. They do not project midpoint real DC away.

The fourteen non-DC bands are exactly `[2^j,2^(j+1))`, `j=0,...,12`, and `[8192,8193)`. Conjugate pairs receive weight 2 and the single Nyquist mode weight 1. Endpoint eigenvalues use `4096*P`; interior eigenvalues use `2048*P`. White eigenvalues `sigma^2` require endpoint PSDs `sigma^2/4096` and interior PSDs `2*sigma^2/4096`; flat one-sided PSD including endpoints is not white.

For each scenario separately, all exact band minima/maxima and complete tie indices are retained. Both implementations form `C_minus`, `C_plus` and the correspondingly weighted `H_minus`, `H_plus`. The errors are weighted by the same band extrema; their maximal row sums produce `delta_minus/plus`. The certified Loewner endpoints are `C_minus-delta_minus I` and `C_plus+delta_plus I`. Negative lower eigenvalues are permissible. No entrywise max/min of matrix endpoints or PSD clipping is performed.

The unchanged global endpoints `(1-rho)*lambda_min*G` and `(1+rho)*lambda_max*G` are retained alongside the band endpoints. Only scalar diagonal and trace intervals are intersected, refusing an empty intersection. Endpoint ratios are returned only for strictly positive scalar lower endpoints; otherwise they are `null`. No domination of global bounds is asserted without evidence.
