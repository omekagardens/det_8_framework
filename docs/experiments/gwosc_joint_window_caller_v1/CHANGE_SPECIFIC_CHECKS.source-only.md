# RI121 change-specific review and future checks

These are exact source-path obligations, not executed checks or a new generic
qualification framework. RI119's41 scientific controls remain fixed and run
inside the child. Those controls do not test these caller-specific boundaries.
Root may separately require actual fabricated caller-control qualification;
no prior changed-target qualification is silently transferred.

| Boundary | Current source path and required refusal/failure |
|---|---|
| Non-authorizing template | Main rejects source-template schema/status; no active freeze/card exists now. |
| Unreviewed active field | source_admission exact normalization permits only declared root-owned slots; changed command/environment/paths/domain fails. |
| Changed scientific bytes | verify_sources and captured whole-body SCIENCE checks fail before first science import. |
| Nonempty scientific input | source_admission requires the exact empty list. |
| Caller or current runtime prerequisite absent | row_body/parsed_row and explicit root schemas/status/identities fail; no guessed success object. |
| Incomplete/unreadable stdlib tree | runtime_support.scan raises traversal errors and compares complete actual membership/pins to root-admitted inventory. |
| Changed/extra runtime symlink | exact ALLOWED_LINKS comparison refuses; resolved framework/site target bytes remain covered. |
| Import origin outside closure | loaded_files fails before/after; no arbitrary ambient source accepted as stdlib. |
| Changed process or import archive | profile equality and absent python311.zip checks fail. |
| Wrong mode/flags/worker or outer command | explicit sys.flags and exact argument checks fail before child launch. |
| Optimized attempted before real normal review | separate mode_admission requires actual normal root adjudication, completed output pins and genuine external completion. |
| Unexpected old output | preflight and exclusive writes refuse root reuse, preserving previous failures. |
| Historical control report substituted | report-envelope labels alone are insufficient; actual captured run completion, full saved audit, genuine child exit and receipts are mandatory. |
| Wrong/truncated/tampered saved scientific result | in-child canonical parse, fresh-reference audit and full independent validator fail; parent checks output bindings and complete declared envelope. |
| Child postcheck fails after report/custody write | worker exit becomes1; parent cannot accept the existing files as success. |
| No sample, monitor failure, wall/RSS/gap violation | exact retained monitor/reap path records failure and terminates/reaps only the owned child group. |
| Mode result differs | optimized postcheck requires entire canonical report bytes and pins equal normal, then rechecks normal custody. |

SOURCE preparation performed only full text review, opaque identity comparisons
and declaration-file consistency checks. These checks do not establish actual
negative-control execution, current runtime identity, numerical resource fit,
external zero exit or scientific qualification.

Repair-specific prospective checks are concretely implemented in
`guard_controls.source-only.py` and described in the execution contract. They
are not yet executed. Root owns a separate exact helper/harness admission and
real process completion. Production runtime/scientific admissions stay absent.
