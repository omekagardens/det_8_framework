The child uses the retained captured loader. All three whole scientific bodies
are captured and matched to fixed pins before any science import. The child
then calls the actual `qualify.run(primary,validator)`, containing all nine cases,
three bounds, twelve groups and41 controls per implementation. It sets genuine

report, re-reads the actual saved bytes, creates a new primary reference itself,
and calls `qualify.audit(saved,primary,validator,reference)` plus the complete
`validator.validate_result(saved['scientific_result'])`. The reference is never
read from the saved report. This second enumeration is intentional: run's own
internal reference is private, and the saved-file audit must own a fresh one.
Thus the worker may enumerate the source-defined912 main signs plus8 bound
factor signs twice; this is a workload declaration, not an observed runtime.

The audit compares saved control records but does not witness historical control
execution. Its exact success object retains historical_controls_reexecuted=false.
The actual captured child's run() call, complete source identity, worker markers,
sole-child external launch/monitor/reap/exit record, and root review supply that
