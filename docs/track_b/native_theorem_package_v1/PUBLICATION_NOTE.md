## Separate application diagnostic

The [one-birth width diagnostic](WIDTH_DIAGNOSTIC.md) connects the original-law
width theorem to an exact observation channel in a finite simulation. It
declares independent held-out arms, the no-gain comparator, a threshold, costs
and a closed PASS/FAIL/ABSTAIN rule. A certified effect bound `0<d<=Delta` and
`n=ceil(4 ln(20)/d^2)` draws per arm bound each error probability by 5% under
the stated sampling assumptions. This is a finite probability argument, not a
measured error rate.

The numerical lower bound and a validated exact sampler are missing. The
benchmark is therefore **ABSTAIN / NOT RUN**. It establishes neither application
advantage nor a physical measurement channel. The mathematical family theorem,
this diagnostic design and an eventual benchmark execution have distinct
completion criteria.

## Separate prospective replay status

The accepted synthetic replay used five fixtures—zero, one, ramp, impulse and
four-tone—with 2,048 samples each, in normal and optimized execution. The six
scientific output bodies agreed byte for byte across modes. Independent review
recomputed the binary64-versus-Decimal80 residual arithmetic using exact
rational representations of the stored numbers, including every sample's
threshold decision. The largest residual was approximately `1.276e-13`, below
the synthetic tolerance `1e-9`; zero was exact, and a deliberate one-percent
gain fault was rejected. These are bounded synthetic results. The reference is
high precision, not an interval enclosure or a general correctness proof.

The prospective observed-data replay has not run. The H1 acquisition attempt
received HTTP 200 with the declared length but no Content-Type header. The
approved method refused it before consuming body bytes. L1 acquisition,
environment staging, decoding and the observed calculation were not started.
That failure remains a failure. A separate narrowly scoped decision is needed
before changing the transport contract and making a new attempt.

No production qualification, historical-identity reconstruction, native gravity
prediction or physical validation follows from either the synthetic result or
the prospective design. Existing custody failures, the GR baseline, Status M
and the RET pause remain unchanged.
