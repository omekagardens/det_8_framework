## 2. Complete small-terminal proof for J(3)

    r<a<A,       a<N,       r<b.

Its maxima are A,N,b. Its only nontrivial automorphism exchanges A,N.
Deleting b leaves the stem-fork T4=(0,1,3,3), with selected precursor
{r}, the singleton slot. Deleting A or N leaves V, with selected
precursor {r,a}, its slot3. These exhaust the maximal-deletion roles.
Three maximal corners in a Ferrers downset require at least3+2+1 cells,
so this five-vertex terminal is non-Ferrers. Deleting the newborn restores
V, proving defect1 and the stated raising classification.

The common deletion base for b and N is the three-chain C3 on r,a,A.
Its two precursors are **1 and3**, root singleton and root-plus-atom.
They are not the pair1,7 used for the different identity J(7)=41p_i.
For arbitrary inherited bits (i,u,v) and arbitrary newborn bits, the
diamond joins the V local node reading (i,u) to the T4 local node reading
only i. V has no relevant automorphism; T4's top swap fixes the selected
root. V's two atom-mark choices are therefore both connected to the same
T4 singleton node at fixed i.

The remaining maximal pair A,N leaves F3, with the same two-chain
precursor used twice. Those are genuine equal-precursor diamonds,
including local-node loops and all newborn/inherited assignments. They
do not change the root invariant or create another node. Thus each
root-bit component has exactly three local nodes: the two V selected

This is a statement about the actual raising-terminal component. It

## 3. Exact hook normalization and its full-complement compensation

Let j_empty be J(0), independent of every record bit because its local
precursor is empty. Let j_root,i be J(1), which reads only i. Define

    A_i := j_empty+j_root,i+z_i > 0,
    t_(i,u) := J(15), the genuine V full probability.

All six proper slots of V have now been accounted for individually.
Their component statements imply that the full complement also depends
only on i,u, not on the excluded tip/leaf bits. This follows by complete
normalization; the full record itself has not been replaced by a local
record. The exact identity is

    A_i+L_i+f_i+g_(i,u)+t_(i,u) = 1,
    B_i := 1−A_i−L_i−f_i = g_(i,u)+t_(i,u) > 0.          (5)

In particular

    g_(i,0)−g_(i,1) = t_(i,1)−t_(i,0).                  (6)

The two terms in (6) are correlated probabilities in the same fixed
row family, not an assigned nuisance slack. With maxima/minima over the
two actual atom-bit choices, (5) also gives

    g_i^- = B_i−t_i^max,
    g_i^+ = B_i−t_i^min,
    g_i^+−g_i^- = t_i^max−t_i^min.                       (7)

Strict positivity yields the stronger-than-bare-row bound

    0 < g_i^- <= g_i^+ < 1−A_i−L_i−f_i,
    0 < L_i < 1−A_i−f_i < 1,
    0 < p_i < 1/41.                                     (8)

The last rational bound is a symbolic normalization consequence of the
held chain ratio; it does not evaluate the actual p_i.

For the branch quantity from RI151, (7) proves the exact identities

    H_i = L_i−f_i/2−g_i^-
        = 2L_i+f_i/2+A_i+t_i^max−1.                     (9)

The genuine full complement is load-bearing. Removing it would destroy
the equality and its exact zero threshold. Define

    T_i := 1−2L_i−f_i/2−A_i.

Then, with no branch selected,

    H_i > 0  iff t_i^max > T_i,
    H_i = 0  iff t_i^max = T_i,
    H_i < 0  iff t_i^max < T_i.                          (10)

In particular strict positivity in (5) gives

    2L_i+f_i/2+A_i−1 < H_i < L_i−f_i/2.                 (11)

Thus 2L_i+f_i/2+A_i >= 1 is a sufficient positive-branch condition;
L_i <= f_i/2 is a sufficient strictly negative-branch condition. These
are sufficient conditions to be proved for the unchanged prefix, not
claims that its actual values meet either one. At equality in the first
condition H_i is still strictly positive because t_i^max>0; equality
in the second still gives H_i<0 because g_i^->0.

The fork-proper entry and the genuine full complement in Z are both

    R_(i,u,s) = 1−(e_i/v_i)(g_(i,u)+g_(i,s)),
    Z_(i,u,s) = D_i−(e_i/v_i)(g_(i,u)+g_(i,s)).           (13)

For the three unordered pair choices00,01,11 this proves

    Z_(i,0,0)+Z_(i,1,1) = 2Z_(i,0,1),
    R_(i,0,0)−R_(i,1,1)
       = 2(e_i/v_i)[t_(i,0)−t_(i,1)].                  (14)

These are exact actual-row correlations. The last line combines the

Taking the larger diagonal Z in (13) gives another exact branch test:
