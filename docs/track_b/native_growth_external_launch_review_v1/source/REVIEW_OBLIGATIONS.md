# RI138 source review obligations

These are prospective review questions for the concrete external launcher,
not executed controls or new scientific gates. Author metadata and literal
source checks provide no execution credit. Independent review must examine
the complete new code and the exact preserved dispatcher contract.

| Boundary | Required evidence in source | Refusal meaning |
| --- | --- | --- |
| Initial authority | Externally pinned root plan, whole handoff and real bootstrap evidence; actual tool origin reserved to root | Missing provenance cannot be repaired by a local success flag |
| Source authentication | Complete helpers authenticated before whole non-main loading; all 396 dependencies retained | An early hash refusal does not test a deeper policy |
| Preparation | Full frozen before inventory, delegated exact cards, independent after observations and real completion | Partial cards after failure are not authority to run |
| Command binding | Plan hash external to plan; authorization hash external to authorization; root dispatch before actual invocation | No circular digest or reconstructed tool success |
| Run startup | Fresh complete before observations plus authentic completed preparation | Stale preparation alone is insufficient |
| Owned process | New group, actual leader relation, bounded independent census and both stream drains | Fast no-live sample, malformed census or overrun is failure |
| Cleanup | Original first error, independent termination/reap/close attempts, empty group only after actual leader reap | No nominal child success can erase collection failure |
| Post custody | All frozen objects attempted independently after ordinary failure; pure spec extension | Never replace old expectations with changed actual bytes |
| Durability | Exclusive capped writes, partial counts, `fsync`, close errors and actual terminal completion | Missing final receipt or failed writer remains a raw failure |
| Result semantics | Exact RI136 envelope, source/card bindings and distinct native/audit result contract | Direct policy success is not production qualification |

Source-only defenses do not demonstrate that their branches have executed.
Future fault injection would require a separately reviewed and genuinely
admitted test plan; it cannot be accomplished by modifying a sealed source,
patching module globals or silently reusing an operational reservation.

The permitted next action after this source handoff is independent review and
owner adjudication. Execution remains unadmitted. Measurement remains separate,
RET remains paused, and no change to scientific claims follows from this work.
