# DET v8.0 — Track B: The Lost Law Problem (κ-Obscured Discoverability)

**Date:** August 10, 2026
**Status:** New Track-B analysis
**Question:** If laws can grow and κ is mutable, can a present event permanently obscure a previously-discovered law? The law still exists in L. But is it ever discoverable again?

---

## 1. The Problem

DET's position (F10): L can grow by extension. Old branches remain; new branches are added. Nothing lawful becomes unlawful.

But κ is mutable — it can increase through damage, trauma, catastrophe. High κ constrains Ω — the possibility space shrinks. If κ increases enough, a previously-accessible branch of L may become INACCESSIBLE.

**The law still exists. It is part of L. But no present moment can reach it from the current record state.**

---

## 2. Three Types of Inaccessibility

| Type | L status | κ status | Can it be rediscovered? |
|---|---|---|---|
| **Forgotten** | Law still in L | κ low — path is open | Yes — just need to look again |
| **Buried** | Law still in L | κ high — path is blocked | Only through κ-reduction (Grace/Jubilee) |
| **Lost** | Law still in L | κ maximal — path is closed | Only if L is extended from a different path |

---

## 3. The Library Analogy

A library contains all books (L has all law branches). The catalog tells you where each book is (Ω shows possible paths). κ is rubble blocking the aisles.

- **Forgotten:** You forgot which shelf. The aisle is clear. Walk there and find it.
- **Buried:** The aisle is blocked by rubble (high κ from a collapse). The book is there. You can't reach it without clearing the rubble (κ-recovery / Jubilee).
- **Lost:** The aisle collapsed completely. The book exists but no path leads to it. You'd need to build a new wing (L extension from a different starting point) to reach that section.

---

## 4. DET Formalization

A law branch \(b \in L\) is **discoverable** from record state \(\mathcal R^-\) if:

\[
\exists \text{ path } \mathcal R^- \rightarrow \cdots \rightarrow \mathcal R_b \text{ such that } b \text{ is accessed at } \mathcal R_b
\]

A law branch is **κ-obscured** if all paths to it require traversing record states with κ above a threshold where Ω no longer includes the branch.

**Key insight:** κ-obscured laws are not DELETED from L. They are UNDISCOVERABLE from the current state. This is a discoverability problem, not an existence problem.

---

## 5. Implications

### 5.1 Lost civilizations

A civilization discovers advanced physics (adds branches to L). Then collapses (κ spikes — war, catastrophe). The knowledge is not destroyed — it's still in L. But the record-path to it is blocked by accumulated κ. Future civilizations must either:
- Reduce κ enough to clear the path (Jubilee), or
- Discover the same laws independently through a different path (L extension from a new starting point).

### 5.2 The "dark ages" as κ-accumulation

Historical periods of lost knowledge are not "regression" in the sense of laws being forgotten. They are κ-accumulation events — structural history (trauma, collapse, institutional destruction) blocking access to previously-discovered law branches.

### 5.3 Resurrection and identity

A person's complete record exists in R. But if κ from death blocks the path to reactualizing that record, resurrection requires κ-reduction — clearing the rubble so the path to the person's identity is accessible again.

### 5.4 Grace and Jubilee as path-clearing

Grace (Ω-enlargement) opens new possible paths. Jubilee (κ-reduction) clears blocked paths. Together, they restore discoverability of laws that were never lost — only buried.

---

## 6. The Deepest Formulation

> A law discovered is never destroyed. It is added to L — permanently. But the path to it can be buried. κ is the weight of history that blocks the aisles of the library. The books remain. Whether we can reach them depends on whether we can clear the rubble.

> This is why Jubilee matters: it is not about erasing the past. It is about clearing the paths the past has blocked — so we can reach what was always there.

---

## 7. Observable Consequences

- **κ spikes correlate with knowledge loss.** Archaeological evidence of civilization collapse should show κ signatures.
- **Rediscovery follows κ-reduction.** Periods of renaissance should correlate with structural recovery.
- **Independent rediscovery is possible.** The same law can be reached through different paths — L extension from different starting points.
