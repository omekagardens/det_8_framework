physical feasibility, model selection or measured application benefit.

**Remaining dependency decisions**

The comparator's observed RET closure uses eleven files under `det8/ret`:
`__init__.py`, `_codec.py`, `_planning.py`, `_score_arithmetic.py`,
`contracts.py`, `covariance.py`, `inference.py`, `provenance.py`, `replay.py`,
`validation_resources.py` and `workflow.py`. It also needs the modified
`relational_tomography.py` helpers `_chi_square_quantile`, `_finite_vector`
and `_mahalanobis_from_cholesky`; the published scheduler is sufficient.
No `det8.core` module was loaded or required in the captured demo closure.
The RET provenance inventory hashes 42 paths, while the captured run loads
18 local sources: 29 hashed paths are not loaded, and two applied helpers plus
three package initializers are loaded without inclusion in that identity.
That inventory is neither the execution closure nor a complete binding of
the applied demo. Publishing every hashed SDK path is not a substitute for
reviewing the actual prerequisites and provenance contract.

The five deferred claims paths are `det8/claims.py`,
`scripts/export_claim_registry.py`, `docs/CLAIM_REGISTRY.md`,
`det8/tests/test_claim_boundaries.py` and `det8/tests/test_claim_summary.py`.
The module's standard-library runtime does not make the package standalone:
it advertises unpublished core support and RET preview surfaces. Its checks
also need current event/legacy/validation boundaries and Track A/gravity
refusals absent from the published source. The generated reference has 35
distinct file targets: 23 are already identical remotely, four are modified
locally and eight are absent remotely at the audit base. Historical G1 source
evidence must not be inherited by later source changes. Preserving the legacy
claim JSON digests means preserving the local accepted baseline; it is not a
backward-compatibility claim about an already published claims API. These
claim checks do not directly require the whole RET implementation or G2 banks.

The measured pilot remains dependent on a selected instrument/dataset,
target and tolerance, noise or deterministic error assumptions, acquisition
costs, conventional baseline and held-out evaluation. Publication of synthetic
or structural tools does not discharge these requirements.
