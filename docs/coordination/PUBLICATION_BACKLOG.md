**Research and identifiability checkpoint**

The candidate starts from published commit
`9a0832939435c5d998cf680135d23a3d353af8db`. Its fifteen selected source paths
need only existing package initializers, published research consumers and the
standard library at runtime. Pytest is a development test dependency; no local
packaging configuration, core, RET, claims module or measured data is needed.
Independent source and mathematical review found no publication blocker.

Verification in the isolated candidate passed **203 focused pytest cases**
(47 kernel, 48 certificate, 108 identifiability) and **90 legacy research
checks** across nine groups, with no failures or errors. Only eight runner
groups differ from the published runner; the ninth kernel group is already
identical. The coordinator verified the remaining runner functions and
top-level statements against the published version. The full working runner
contains unrelated baseline work and is deliberately not the staged source.
The original working file is preserved while the reviewed snapshot is staged.

The research interface includes numerical refusal and tolerance contracts,
not exact floating-point positivity certification or public-core promotion.
The identifiability interface certifies a supplied rational linear mean map
on unrestricted real parameters. It returns either a row-space reconstruction
or an exact nullspace counterexample. It does not provide noisy confidence,
physical feasibility, model selection or measured application benefit.

That inventory is neither the execution closure nor a complete binding of
