# Calibration applicability for the selected GWOSC H1 calculation

Reviewed documentary result, 26 October 2026. The selected observation belongs to the published H1/O1/V2/C02 data class. This closes the class-identification question. It does not yet supply numerical calibration errors, a timing guarantee or an uncertainty distribution for the final statistic.

The retained [input descriptor](../experiments/gwosc_input_qualification_v1/INPUT_REPORT.json) identifies the 32-second H1 V2 file beginning at GPS 1126259446, sampled at 4096 Hz; the selected event interval is GPS [1126259462, 1126259463). These are historical descriptor statements, not a new binary acquisition, identity reconstruction or custody repair.

[GWOSC technical details](https://gwosc.org/techdetails/) identify V2 GW150914 data as C02 calibrated. The [O1 release](https://gwosc.org/O1/) places the observation in its published run interval and describes its C02 strain products. This establishes a documentary class match. The corrected offset described for an earlier data version is not a residual timing bound for this calculation.

The [LIGO uncertainty catalogue](https://dcc.ligo.org/T2100313/public) lists an O1 archive. Its [README](https://dcc.ligo.org/public/0177/T2100313/003/README) describes hourly GPS-named FinalResults products and amplitude/phase uncertainty for the ratio of true to modelled response. Those descriptions do not identify the archive member applicable to this exact interval, supply its validity and interpolation rules, or establish a joint uncertainty model for the processed statistic. A configuration epoch is not a statement that each hourly estimate is valid throughout that epoch. O1/O2 products also differ from the later MinMax format.

One possible route is a manifest identifying the applicable H1 C02 uncertainty member, its exact version, time coverage, selection/interpolation rule and response convention. That is a proposed input specification, not a file found or accepted in this review. A separately justified event-specific product or conservative observation bound could be another route; neither alternative has been adopted. A nearest-hour choice, run-wide maximum or pointwise one-sigma curve is not an admitted substitute without the appropriate justification.

The [recorded processing interface](../experiments/gwosc_nominal_processing_v1/PROCESSING.md) includes finite filtering, whitening and window operations. GWOSC documents zero-phase decimation from 16384 to 4096 Hz and historical duration-dependent processing differences. These facts do not supply an end-to-end deterministic error bound. A nominal passband alone does not make the finite calculation an ideal frequency projection. Response, timing, conversion and selection assumptions must reach the actual statistic through the declared processing interface.

The next measurement step is to specify and review the smallest applicable observation input and its transfer rule. No archive member, new strain array, supplier calibration or numerical propagation was acquired or executed for this documentary result. Historical custody failures remain intact. This is independent measurement work; it neither supplies a DET-native forward map nor validates DET's physical theory.
