# Metadata-obscured research publication

This public derivative contains the reviewed proof manuscripts, research plans,
and historical review summaries from the pending local checkpoints. It retains
conditional mathematics, finite checks, failures, unresolved premises, the RET
pause and the separation between calibration and a native physical forward map.
No new scientific or runtime acceptance is created by publication.

Raw machine, runtime, filesystem-custody and command-transcript JSON, logs,
administrative checker/builder scripts and patches are intentionally withheld.
Local paths, private fingerprints, execution identifiers, platform and location
metadata in prose are replaced with opaque labels. The private correspondence
map and exact original evidence stay local. Referenced withheld files are not
missing evidence that this public copy claims to supply.

Historical statements about complete archives and exact identity checks refer
to the retained private originals. Each new PUBLICATION_MANIFEST.json covers
only the redacted public payloads and lists withheld files. This derivative is
not an executable installation or an independently replayable custody package.

A single new public commit descends from the previously published branch tip.
The pending unredacted local commits are not its ancestors. Previously published
remote history is unchanged; this publication does not erase metadata already
present there. Future publications must extend the sanitized lineage, never
merge or push the private local history into it.
